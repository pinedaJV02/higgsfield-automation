Character references

A prompt automatically pulls in any character whose name or aliases appear in it (e.g. Dog1.png matches "dog"). Add comma-separated aliases under each image to control matching (e.g. dog, puppy, brown dog). The first generated image of a character is then locked and reused for consistency.
